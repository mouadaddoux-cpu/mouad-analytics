How it works

Three steps. No sign-up screen in sight.

Everything happens in the tab you already have open — the file never leaves the machine.

Export your CSV

Any report with campaign, impressions, clicks, spend and conversions. Column names are matched loosely, currencies and thousands separators are handled.

Drop it on the page

Drag the file onto the dashboard or pick one from disk. Parsing is local, so there is no upload spinner and no API quota.

Read the verdict

Five headline KPIs, a spend-vs-CTR trend line and the campaigns that are outperforming the account average — flagged automatically.

Features

Small surface, sharp edge.

Built to answer one question fast: where is the money working, and where is it idling?

KPIs in one glance

Spend, conversions, CTR, CPC and conversion rate — with impressions and click volume kept one line below.

Spend vs CTR trend

Two axes, one chart. Bars show where the budget went per week; the line shows whether the traffic quality followed.

Flagged winners

A campaign is a winner when its CTR beats 1.5× the account average with enough clicks to trust it. No manual sorting.

Nothing leaves the page

No fetch to a server, no analytics script, no cookie banner. The only network request is the page itself.

Forgiving CSV parsing

Quoted fields, $1,204.50, percentages, BOMs, CRLF — all handled before anything is summed.

Deploy anywhere static

Plain HTML, CSS and JS. GitHub Pages, Netlify, a USB stick — same result, because there is no server to configure.
